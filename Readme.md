# Biblioteca POO

## Sobre o projeto

Este projeto é um sistema de controle de biblioteca desenvolvido em Python como parte de uma trilha de estudos. O foco foi a utilização de Programação Orientada a Objetos (POO), trabalhando principalmente com classes, objetos e métodos.

O sistema permite cadastrar livros e usuários. É possível realizar o empréstimo e a devolução dos livros, bem como visualizar todos os livros cadastrados, aqueles que estão disponíveis para empréstimo e os que já estão emprestados.

A validação das informações cadastradas também foi um dos focos do trabalho.

## Funcionalidades

- Cadastrar livro
- Cadastrar usuário
- Listar todos os livros
- Listar usuários
- Realizar empréstimo de um livro
- Realizar uma devolução
- Listar livros disponíveis
- Listar livros emprestados
- Buscar livro pelo título
- Buscar usuário pelo CPF
- Menu interativo
- Encerrar o programa

## Como executar

É necessário ter o Python instalado no computador.

Baixe ou clone este repositório e acesse a pasta do projeto.

Execute o arquivo principal:

```bash
python main.py
```

O programa funciona por meio de um menu no terminal, com opções numéricas de 1 a 10.

Para o cadastro de CPF, é necessário utilizar o seguinte formato:

`XXX.XXX.XXX-XX`

Exemplo:

`235.346.778-09`
